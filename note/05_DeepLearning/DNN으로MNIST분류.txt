MNIST 데이터셋: 0부터 9까지의 손으로 쓴 숫자 이미지 데이터셋입니다. 각 이미지는 28x28 픽셀(총 784개의 픽셀)로 구성됩니다.

데이터 전처리:

Flatten: 2차원(28x28) 이미지 데이터를 1차원(784) 배열로 펼쳐서 모델의 입력으로 사용합니다.

정규화: 픽셀 값을 0~255에서 0~1 사이의 값으로 변환하여 학습 효율을 높입니다.

모델 구조:

입력층: Flatten(input_shape=(28, 28))

은닉층 (Hidden Layers): Dense 층을 여러 개 쌓아 깊은 모델을 구성하며, relu 활성화 함수를 주로 사용합니다.

출력층 (Output Layer): Dense(10, activation='softmax') - 10개의 숫자(0~9)를 분류하므로 10개의 뉴런과 softmax를 사용합니다.
