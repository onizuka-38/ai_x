 Seq2Seq와 어텐션 (Attention)
주로 기계 번역과 같은 입력 시퀀스에 대한 출력 시퀀스를 생성하는 문제에 사용됩니다.

Seq2Seq (Sequence-to-Sequence):

인코더(Encoder): 입력 문장(시퀀스)을 하나의 고정된 크기 벡터,  컨텍스트 벡터(Context Vector)로 압축합니다.

디코더(Decoder): 컨텍스트 벡터를 받아 출력 문장(시퀀스)을 생성합니다.

한계: 입력 문장이 길어지면 모든 정보를 하나의 컨텍스트 벡터에 압축하기 어려워 성능이 저하됩니다.

어텐션 (Attention):

Seq2Seq의 한계를 보완하기 위해 등장한 메커니즘입니다.

디코더가 단어를 예측하는 매 시점마다, 인코더의 전체 입력 시퀀스를 다시 참조하여 현재 예측에 더 중요한 단어에 집중
