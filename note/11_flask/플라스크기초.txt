플라스크는 파이썬으로 웹 애플리케이션을 쉽게 만들 수 있도록 도와주는 마이크로 웹 프레임워크입니다. @ 데코레이터를 활용하여 URL 경로와 실행할 함수를 연결(라우팅)하는 것이 특징입니다.

앱 초기화 및 실행: Flask(__name__)으로 플라스크 애플리케이션 객체를 생성하고, app.run()으로 개발 서버를 실행합니다.

라우팅 (Routing): @app.route() 데코레이터를 사용하여 특정 URL 경로로 요청이 들어왔을 때 어떤 함수를 실행할지 지정합니다.

정적 라우팅: /나 /about처럼 고정된 경로를 지정합니다.

동적 라우팅: /user/<username>처럼 URL의 일부를 변수로 받아 처리할 수 있습니다.

템플릿 렌더링: render_template() 함수를 사용하여 미리 만들어 둔 HTML 파일을 사용자에게 보여줄 수 있습니다. 이를 통해 동적인 데이터를 HTML에 담아 표현하는 것이 가능해집니다.

from flask import Flask, render_template

app = Flask(__name__) # Flask 앱 객체 생성

# 정적 라우팅: 루트 URL('/')에 대한 요청 처리
@app.route('/')
def index():
    return 'Hello, Flask!'

# 동적 라우팅: <name> 부분을 변수로 받음
@app.route('/hello/<name>')
def hello(name):
    return f'Hello, {name}!'

# 템플릿 렌더링: 'index.html' 파일을 렌더링
@app.route('/view')
def view_page():
    # user_info 라는 변수를 HTML 파일로 전달
    return render_template('index.html', user_info='홍길동')

if __name__ == '__main__':
    app.run(debug=True) # 개발용 서버 실행
