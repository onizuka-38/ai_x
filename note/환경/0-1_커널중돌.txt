1 .jupyter 커널 목록에서 삭제 하기 : jupyter kernelspec remove 가상환경이름

2. 가상환경 지우기 : conda env remove --name 가상환경이름

3. 가상환경 생성 : conda create -n ml-dl-nlp python=3.10 

4. 생성한 가상환경으로 전환 : conda activate ml-dl-nlp 

5. pip 최신버전으로 업데이트 : python.exe -m pip install --upgrade pip 

6. pip install jupyter numpy==1.23.5 pandas==1.5.3  matplotlib==3.7.0 seaborn==0.12.2 scikit-learn==1.2.1

7. 가상환경에서 Jupyter를 설치해야 함 : conda install ipykernel

8. 가상환경을 Jupyter에서 선택 가능한 커널로 등록 : python -m ipykernel install --user --name ml-dl-nlp --display-name "ml-dl-nlp"

8. pip install opencv-contrib-python

9. pip install statsmodels==0.13.5

10. pip install pillow

11. conda install -c conda-forge graphviz (의사결정나무 그래프를 생성하는 도구)
12. pip install pydot

13. pip install xgboost==1.7.3
14. pip install lightgbm
15. pip install catboost==1.2

16. 자료불균형(smote)과 앙상블 알고리즘 다운
conda install -c conda-forge imbalanced-learn=0.9.1
