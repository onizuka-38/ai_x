Ollama는 Llama, Mistral과 같은 대규모 언어 모델을 개인 컴퓨터에서 로컬로 실행할 수 있게 해주는 도구입니다. 이를 통해 인터넷 연결이나 API 키 없이 LLM을 사용할 수 있습니다.

import ollama

# 로컬에서 실행 중인 모델과 대화
response = ollama.chat(
    model='llama3', # 로컬에 설치된 모델명
    messages=[{'role': 'user', 'content': '한국의 수도는 어디야?'}]
)

print(response['message']['content'])
