LLM이 단순히 텍스트로만 응답하는 것을 넘어, 개발자가 미리 정의해 둔 외부 함수나 API를 스스로 호출하도록 만드는 강력한 기능입니다. 모델은 사용자의 질문을 해석하여 어떤 함수를 어떤 인자값으로 호출할지 결정하고, 그 정보를 JSON 형식으로 반환합니다.

# 1. API 호출 시 사용할 함수(도구)를 정의
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_current_weather",
            "description": "Get the current weather in a given location",
            "parameters": { ... } # 함수에 필요한 파라미터 정의
        }
    }
]

# 2. 모델이 함수를 호출해야 할 때 'tool_calls'를 반환
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "서울 날씨 어때?"}],
    tools=tools,
    tool_choice="auto"
)
response_message = response.choices[0].message

# 3. 반환된 tool_calls가 있으면 실제 함수 실행
if response_message.tool_calls:
    # ... 여기에 실제 함수(get_current_weather) 실행 코드를 작성 ...
