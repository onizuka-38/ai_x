# 제품별 소비자 리서치 요약 보고서 (신뢰도 점검 반영판)

- 작성일: 2025-08-14

## 덴마크 하이그릭요거트 400g
- 카테고리: 우유류 / 발효유 / 호상-중대용량
- 구매 빈도(요약): 마시는 요거트 대비 구매 빈도는 낮지만 정기적 소비(가정 비축·행사 영향).
- 주 구매 채널: 대형마트 중심, 동네슈퍼·편의점 보조.
- 정보 습득 채널: 매장 진열 중심, TV·온라인 광고/후기 병행.
- 구매 계기(트리거): 행사(1+1·묶음), 선호 브랜드, 가격 인하.
- 주 소비자(핵심 타깃): 중장년층 비중 높고, 20~30대에서도 건강·플레인 선호 확산.
- 구매 고려 요인: 가격, 브랜드 신뢰, 성분·영양, 유통기한.
- 만족도/특징: 맛·편의성 만족도 높음(공개 조사 공통 결과).
- 데이터 범위 메모: 발효유(떠먹는) 카테고리 경향(정성 요약).
- 출처(요약): KREI 가공식품 소비자태도조사(2024), aT FIS 세분시장/조사보고서.

## 동원맛참 고소참기름 135g
- 카테고리: 참치 / 참치캔 / 라이트스탠다드참치
- 구매 빈도(요약): ‘즉석반찬’ 콘셉트로 정기·수시 구매 혼재(브랜드·행사 영향).
- 주 구매 채널: 대형마트·동네슈퍼 중심, 온라인은 보조 채널.
- 정보 습득 채널: 매장 진열/레시피·광고 노출.
- 구매 계기(트리거): 행사(1+1/묶음), 신제품 체험, 즉석반찬 활용.
- 주 소비자(핵심 타깃): 전통 40~50대 주부 + 20~30대로의 확장.
- 구매 고려 요인: 맛/풍미, 가격, 보관·편의성, 브랜드 신뢰.
- 만족도/특징: ‘캔째 바로 먹는’ 편의성 호응.
- 데이터 범위 메모: 브랜드 신제품 특성 + 가공식품 일반 조사(정성) 기반.
- 출처(요약): 동원F&B 보도자료, KREI(2024), aT FIS 조사보고서.

- 구매 빈도(요약): 상비형 조미액: 필요 시 수시 구매(정기빈도 낮음).
- 주 구매 채널: 대형마트·온라인 중심.
- 정보 습득 채널: 레시피·유튜브·후기 노출 기반 인지.
- 구매 계기(트리거): 간편한 감칠맛, 요리 난이도↓, 레시피 노출.
- 주 소비자(핵심 타깃): 맞벌이/자취·요리 초보, 간편식 선호 가구.
- 구매 고려 요인: 맛(감칠맛), 다용도성, 나트륨/원재료, 가격.
- 만족도/특징: 재구매율 우호적(정성).
- 데이터 범위 메모: 액상 조미료 카테고리 인사이트(정성) 요약.
- 출처(요약): aT FIS 세분시장·조사보고서, 브랜드 리포트.
